M04 · Chapter 4

Share classes trade front-end loads against ongoing fees

CONNECTTHE IDEAS

Class A · front-end load 0–4.5%; no back-end load; 0.25% 12b-1 fee; 0.7% expense ratio

Class C · no front-end load; back-end load 0–1%; 1.0% 12b-1 fee; 0.7% expense ratio

Class I · no front-end or back-end load; no 12b-1 fee; 0.7% expense ratio

Class A load tapers with investment size; the source starts at 4.5% below $50,000 and reaches zero above $1 million.

Class C exit fee is 1% when shares are redeemed within one year.

Class I shares are described in the source as institutional shares with lower distribution fees.

How to filter for ETFs in FactSet’s Universal Screening tool

The goal of this step is to narrow your search from all possible securities down to just ETFs.

Locate the Filter: On the left-hand side of the Universal Screening interface, you'll see a section for filters. Look for an "Add Filter" button or a search bar within that section.

Search for Security Type: In the filter search bar, type "Security Type". Select it when it appears in the results.

Set the Criteria: A new filter criteria box will appear. Change the operator from the default to "Is equal to".

How to filter for ETFs in FactSet’s Universal Screening tool

Select ETF: From the list of security types, find and select "ETF (Exchange Traded Fund)"

If you want to further refine your results to only include ETFs that trade on major US stock exchanges (like the NYSE or NASDAQ), you can add another filter.

Add a New Filter: Follow the same process as above to add a new filter.

Search for Exchange: In the filter search bar, type "Exchange". Select it when it appears.

How to filter for ETFs in FactSet’s Universal Screening tool

Set the Criteria: Change the operator to "Is equal to".

Select the Exchanges: From the list of exchanges, select "NYSE Arca" and "NASDAQ". You can select multiple items by holding down the Ctrl (or Command) key while clicking.
