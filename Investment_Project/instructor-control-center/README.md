# BUS331 Investment Project — Instructor Control Center

This folder is the private source for materials released only when and to whom the instructor chooses. Do not copy its contents into the public project repository or student-facing pages.

## Release folders

- `client-role-play/` — sealed client cards and the classroom demonstration card for Phase 1.
- `scenario-reveals/` — Phase 2 Scenario Reveal packets, held until the baseline checkpoint is complete.
- `release-log.md` — a simple record of what was released, to whom, and when.

## Instructor routine

1. Run the classroom demonstration before team client discovery.
2. Give only the designated client-role student each sealed card; the remaining team members interview and take notes.
3. Confirm the baseline checkpoint is submitted before releasing a Phase 2 Scenario Reveal packet.
4. Record each release in `release-log.md`.
